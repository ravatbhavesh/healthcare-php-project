# CarePlus Healthcare (PHP + MySQL)

Educational starter project. Do not use real patient information or deploy this demo for real clinical use without a security and privacy review.

## Requirements
- XAMPP (Apache + PHP + MySQL/MariaDB)
- A modern browser
- Internet connection for the Bootstrap CDN

## Run locally
1. Copy the `healthcare_php_project` folder into XAMPP's `htdocs` directory.
2. Start Apache and MySQL in the XAMPP Control Panel.
3. Open `http://localhost/phpmyadmin`.
4. Import `database/healthcare.sql` (it creates `healthcare_db`).
5. Check `config/database.php` and adjust the MySQL username/password if needed.
6. Open `http://localhost/healthcare_php_project/`.
7. Test appointment requests from the Book Appointment page.

## Create a demo login
The login page expects a user record whose `password_hash` was generated by PHP `password_hash()`. From a temporary local PHP file, run:
```php
<?php
echo password_hash('DemoPass123!', PASSWORD_DEFAULT);
```
Copy the printed hash, then execute this SQL in phpMyAdmin:
```sql
USE healthcare_db;
INSERT INTO users (name, email, password_hash, role)
VALUES ('Demo Patient', 'patient@example.com', 'PASTE_HASH_HERE', 'patient');
```
Log in with `patient@example.com` and the password `DemoPass123!`.

## Included
- Responsive homepage
- Appointment request form stored in MySQL
- Login/logout with password verification and session regeneration
- Basic dashboard listing appointments associated with the signed-in user's email
- MySQL schema and starter styling

## Limitations / before real use
This is a college-project starter, not a complete healthcare system. It does not yet implement a full admin/doctor management UI, CSRF tokens on all forms, appointment collision enforcement, audit logging, or a complete medical-record authorization model. Add and test these before expanding it. Never put real patient data in a demo deployment.
